PRAAN Volunteer Management v2.2.1 — cPanel আপডেট নির্দেশিকা
=========================================================

এই প্যাকেজ app.praan.org.bd/a/volunteer/ পাথে বসানোর জন্য তৈরি।

১) প্রথমে cPanel থেকে সম্পূর্ণ সাইটের, SQLite-এর এবং ছবির BACKUP নিন। বিশেষভাবে:
   storage/pran.sqlite
   storage/photos/
   storage/update_signer.pub
   storage/update_backups/
   storage/maintenance.json
   (এগুলো মুছবেন বা খালি ফাইল দিয়ে প্রতিস্থাপন করবেন না।)

২) আপনার সাবডোমেইনের Document Root অনুযায়ী a/volunteer/ ফোল্ডারে যান।
   নতুন ZIP-এর সব প্রোগ্রাম ফাইল সেই ফোল্ডারের সরাসরি root-এ রাখুন।
   ZIP Extract করার পরে index.php এবং .htaccess a/volunteer/ এর ভেতরে থাকতে হবে।
   পুরোনো SQLite, ছবি, signing key ও backup ফাইল অক্ষত রাখুন।

৩) cPanel MultiPHP/Select PHP থেকে PHP 8.1+; pdo_sqlite, sqlite3, curl,
   zip, sodium, fileinfo, gd সক্রিয় আছে কি না পরীক্ষা করুন।
   GitHub Update-এর জন্য আউটবাউন্ড HTTPS (api.github.com) প্রয়োজন।

৪) /a/volunteer/index.php?page=system_doctor
   /a/volunteer/index.php?page=updates
   /a/volunteer/index.php?page=notifications
   এই তিনটি পৃষ্ঠা Super Admin হিসেবে খুলে পরীক্ষা করুন।
   Ctrl + Shift + R চাপুন; OPcache থাকলে PHP version switch/restart দিয়ে cache পরিষ্কার করতে পারেন।

৫) GitHub রিপো ডিফল্ট: ronyopq/Volunteer-Hub
   System > Settings-এ GitHub auto-check চালু রাখতে পারবেন এবং 6/12/24 ঘণ্টা নির্বাচন করতে পারবেন।
   Update Center-এ 'এখন যাচাই' চাপলে তৎক্ষণাৎ চেষ্টা করবে।
   নতুন Commit এলে নোটিফিকেশন হবে, কিন্তু তা ইনস্টলযোগ্য Release নয়।

৬) নিরবচ্ছিন্ন/সাইটে কেউ না ঢুকলেও স্বয়ংক্রিয় পরীক্ষা চাইলে cPanel > Cron Jobs:
   0 */6 * * * /usr/local/bin/php /ABSOLUTE/PATH/TO/a/volunteer/tools/check_github_updates.php
   সার্ভারের আসল PHP binary ও absolute path ব্যবহার করুন। এটি শুধু CLI থেকে চলবে।
   এটি কোনো সোর্স-কোড স্বয়ংক্রিয়ভাবে ইনস্টল করে না; শুধু ডাটা চেক ও অ্যাডমিনদের নোটিফিকেশন তৈরি করে।

৭) One-Click Update ব্যবহার করতে অবশ্যই নিজস্ব Trusted Ed25519 Public Key বসাতে হবে।
   Offline release signer (tools/release_signer.php) দিয়ে তিনটি সম্পদ বানিয়ে GitHub Release-এ দিন:
   pran-update-vX.Y.Z.zip
   pran-update-vX.Y.Z.zip.sha256
   pran-update-vX.Y.Z.zip.sig
   Release tag: vX.Y.Z। শুধুমাত্র Super Admin পাসওয়ার্ড + UPDATE confirmation দিয়ে ইনস্টল করবেন।
   PRIVATE KEY কখনো GitHub বা Hosting-এ দেবেন না।

৮) Error Pages: 403/404/500/503 HTML ফাইল errors/ ফোল্ডারে আছে।
   .htaccess এর ErrorDocument path /a/volunteer/ ধরে লেখা।
   ভিন্ন path হলে ErrorDocument path পরিবর্তন করুন।
   PHP error এ 'ERR-...' দেখালে storage/runtime-errors.jsonl ও private PHP log দেখুন।
   এই লগ কেবল সার্ভার অ্যাডমিনের জন্য; কখনো পাবলিক করবেন না।

নিরাপত্তা: কোনও production database বা ব্যবহারকারীর ব্যক্তিগত তথ্য এই ZIP-এ নেই।
প্রথমবার আপডেটটি cPanel দিয়ে ইনস্টল করুন; তারপর পরবর্তী signed GitHub Release ব্যবহার করা যাবে।


নতুন SMART IMPORT (v2.2.1)
-------------------------
১) Super Admin/Admin হয়ে ?page=import খুলুন।
২) আগে থেকে থাকা volunteers ও ছবির সম্পূর্ণ ব্যাকআপ নিন।
৩) আপনার Excel (27 rows / 119 columns) অথবা দেওয়া Import-Ready CSV বেছে নিন।
৪) "Update Existing + Import New" সিলেক্ট থাকলে আগের ID/NID মিলে যাওয়া রেকর্ডে কেবল পূরণ করা ফিল্ড আপডেট হবে; বাকি নতুন হবে।
৫) "Only New Records" চাইলে পুরোনোগুলোর পরিবর্তন হবে না।
৬) Preview-তে প্রতিটি সারির New / Update / Review / Invalid যাচাই করে Confirm করুন।
৭) নতুন ও আপডেটের মোট সংখ্যা মেলান; Review সারি থাকলে সংশ্লিষ্ট রেকর্ড ম্যানুয়ালি যাচাই করুন।
৮) একই নাম এবং শেয়ার্ড মোবাইলের কারণে রেকর্ড বাদ দেওয়া হবে না।

সতর্কতা: একই NID-এর বিপরীত তথ্য বা এক ফাইলে এক Volunteer ID একাধিকবার থাকলে রেকর্ড নিরাপত্তার কারণে Review-তে যাবে।
PHP ZIP ও DOM না থাকলে .xlsx-এর বদলে CSV ফাইল ব্যবহার করুন। এই ZIP-এ ব্যক্তিগত স্বেচ্ছাসেবকের ডাটা নেই।
